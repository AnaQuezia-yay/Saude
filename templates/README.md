# 🤖 Sistema de guia preventivo com ChatBot

Este repositório reúne diferentes **arquivos** de construção de um sistema em Python. ****, explorando abordagens distintas — desde fluxos guiados e sistemas baseados em regras até o uso de bibliotecas de Processamento de Linguagem Natural (PLN).

---

## 📂 Estrutura do Repositório

Cada script pode ser executado separadamente e demonstra uma etapa ou abordagem diferente de desenvolvimento:

| Pasta | Arquivo | Tema | Abordagem Técnica |
| :--- | :--- | :--- | :--- |
| `tempates` | `index.htm` / `chatbot.htm` | Simuador Mobile em html | Estrutura e funcionaidades |
| `static` | `style.css` | Estilo | Instruções para o estilo das telas |
| --- | `app.py` | Funcionaidades e execução | Fluxo entre as teas e execução do chatbot |



## ⚠️ Aviso Importante
O sistema têm finalidade **exclusivamente educacional e experimental**. As respostas são orientações gerais automatizadas e **não substituem** avaliação médica ou atendimento profissional de saúde.
